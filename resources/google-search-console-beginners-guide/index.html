Google Search Console: a complete beginner's guide

By Reckona AIUpdated 28 July 20269 min read

Search Console is free, directly from Google, and most businesses either never set it up or set it up once and never look again. It's the only place that shows you exactly how Google sees your site — here's how to actually use it.

Setting up your property correctly

StepWhat to get right
Choose the right property typeDomain property (covers all subdomains/protocols) vs URL-prefix (one exact URL) — Domain is usually the better default if you can verify via DNS
Match your actual live domainIf your site serves from the non-www version, verify that exact version — a www/non-www mismatch causes submission errors
Verify ownershipDNS record, HTML file upload, or existing Google Analytics/Tag Manager connection

Submitting your sitemap without errors

Under Sitemaps, type only the path relative to your verified property — usually just sitemap.xml, not the full URL. Pasting the complete https://yoursite.com/sitemap.xml into a field that already assumes your domain prefix is the most common cause of an "invalid sitemap address" error.

The reports worth checking weekly

  • Performance report — your actual search queries, impressions, clicks and average position. The single most useful free keyword data source you have.
  • Pages report (Indexing) — which pages are indexed vs excluded, and why.
  • Sitemaps — confirm your submitted sitemap's discovered vs indexed count isn't drifting apart.
  • Core Web Vitals — flags performance issues Google considers a ranking factor.

The habit that pays off: checking the Performance report monthly for queries where you rank position 8–15 — these are your fastest wins, already getting some visibility and close to breaking onto page one with a small content improvement.
